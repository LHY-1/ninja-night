# 忍者之夜 · 局域网版

零依赖的局域网身份推理游戏：一台电脑当主机，同一 WiFi 下的手机 / 平板 / 电脑用浏览器就能加入，无需安装任何 App。

## 运行

1. 安装 [Node.js](https://nodejs.org/)（建议 ≥ 18）
2. 在本目录执行：

   ```bash
   node server.js
   ```

3. 启动后终端会打印局域网地址（形如 `http://192.168.x.x:7788`），其他人用浏览器打开即可
4. Windows 用户可以直接双击 `start.bat`

换端口：`PORT=8000 node server.js`

## 玩法速览

- 4–11 人，一人开房，其他人输入 4 位房号加入
- 每轮先抽牌，夜晚按顺序召唤五种忍牌：密探 / 隐士 / 骗徒 / 刺客 / 上忍
- 每人可以给其他玩家做**私人身份标记**（只有自己可见）
- 荣誉标记自带分值，累计总分率先达到 10 分者获胜
- 出局后仍可旁观与聊天，建议当面玩效果最佳

## 文件结构

```
server.js   服务端（静态页面 + JSON 接口 + SSE 推送）
engine.js   规则引擎（纯逻辑，不碰网络）
public/     前端（index.html / app.js / style.css）
start.bat   Windows 一键启动
```

## 说明

- 服务端零 npm 依赖，克隆即用
- 房间状态保存在内存中，服务重启即清空
- 仅设计用于可信的局域网环境，请勿直接暴露到公网
